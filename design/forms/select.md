# Select

**Structure:** trigger button, a chevron icon, and a menu that opens below.
**Built on:** Radix UI Select.

## Trigger
Height 40px, same shape as Input. Placeholder in color-text-muted.

## Menu
Background color-bg, 1px border color-border, shadow-md, radius-md, padding 4px, max-height 240px with scroll.

## Items
Height 36px, padding-x 12px. Highlighted: background color-muted. Selected: check icon on the right.

## Behavior
Arrow keys move, Enter selects, Escape closes, typing jumps to a matching item.
