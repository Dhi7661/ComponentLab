# Checkbox

**Structure:** box, then label to the right (8px gap, text-sm).

## Shape
Box 16px, radius-sm, 1px border color-border.

## States
- checked: background color-primary, check icon in color-on-primary
- indeterminate: background color-primary, dash icon
- hover: border color-primary
- focus-visible: ring-focus
- disabled: opacity 50%

## Accessibility
Native input type="checkbox", styled visually. Set indeterminate through the DOM property.
