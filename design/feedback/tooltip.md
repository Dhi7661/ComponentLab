# Tooltip

**Structure:** trigger element and a bubble.
**Built on:** Radix UI Tooltip.

## Shape
Background color-text (inverted), text color-bg, text-xs, padding 6px 8px, radius-sm, max-width 240px. Arrow 6px.

## Behavior
Shows after a 300ms delay on hover or keyboard focus. Hides on mouse leave, blur, or Escape. Default side is top.

## Accessibility
Bubble is linked to the trigger with aria-describedby. The trigger keeps its own accessible name.
