# Alert

**Structure:** icon, title, optional description, optional dismiss button.

## Shape
Padding 16px, radius-md, 1px border in the tone color. Background is the tone color at 10% opacity. Title text-sm, weight 600. Description text-sm.

## Tones
- info: color-info
- success: color-success
- warning: color-warning
- error: color-danger

## Accessibility
Error and warning use role="alert". Info and success use role="status".
