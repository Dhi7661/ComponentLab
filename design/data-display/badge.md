# Badge

**Structure:** inline pill, optional leading dot, text.

## Shape
Height 20px, padding-x 8px, text-xs, weight 500, radius-full.

## Tones
- neutral: background color-muted, text color-text
- primary: background color-primary at 10% opacity, text color-primary
- success, warning, danger, info: same pattern using their tokens

## Accessibility
The text always states the meaning. Color is never the only signal.
