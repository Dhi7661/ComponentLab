# Avatar

**Structure:** circle with an image, or initials when there is no image.

## Sizes
sm 32px, md 40px (default), lg 56px.

## Shape
Circle (radius-full), image cover-fit. Fallback: initials on color-secondary, text color-on-secondary, weight 600, text size scaled to the avatar size.

## Accessibility
Image requires an alt prop. Initials fallback uses aria-label with the full name.
