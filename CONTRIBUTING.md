# Contributing to ComponentLab

Thanks for your interest in contributing.

## Before you start

1. Read CONVENTIONS.md.
2. Check open issues to avoid duplicate work.
3. For a new component, open an issue first so the design can be agreed on.

## Setup

```bash
npm install
npm run dev
```

## Making a change

1. Create a branch named after the change, for example `fix/input-error-announcement`.
2. Make one change per commit, using the format in CONVENTIONS.md.
3. Run `npm run lint`, `npm run test`, and `npm run build` before you push.
4. Open a pull request with a short description. Add screenshots for visual changes.

## Pull request checklist

- [ ] Tests added or updated
- [ ] Keyboard use and accessibility checked
- [ ] Works in light and dark mode
- [ ] Registry entry updated if props changed
- [ ] README updated if usage changed

## Conduct

Be respectful and constructive in issues and reviews.
